# Mine-a-Mountain-Script
Roblox Script for place Mine a Mountain.

Чтобы не вставлять весь код в ваш инжектор, используйте эту ссылку:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Skeltx/Mine-a-Mountain-Script/refs/heads/main/MaM.lua"))()
```
Проверен на инжекторе Xeno. Не требует ключа.

### Описание
Данный скрипт основывается на чужом скрипте, чей автор мне неизвестен.

Всё, чем отличается этот скрипт от основного — это новыми вкладками и в целом новым "блоком" в коде. Его особенность заключается в том, что новый блок кода можно вставить в любую из новых версий основного скрипта.

А ещё хочу выделить, что весь "новый блок кода" — это бред дипсика, но довольно-таки хороший. Я только корректировал всё и проверял по поводу UI (как всё выглядит).
