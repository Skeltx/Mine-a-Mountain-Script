# Mine-a-Mountain-Script
Roblox Script for place Mine a Mountain.

Данный скрипт основывается на чужом скрипте чей автор мне не известен.
Всё чем отличается данный скрипт от основного, это новыми вкладками да и в общем в коде новым "блоком", чья особенность заключается в том что новый блок кода можно вставить в любую из новых версий основного скрипта.
А ну и хочу выделить что весь "новый блок кода" это бред дипсика, но довольно таки хороший. Я только корректировал всё и проверял по поводу UI как всё выглядит.
