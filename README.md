# Mine a Mountain Script (MaM)

Полнофункциональный скрипт-помощник для Roblox-игры **Mine a Mountain** («Добудь гору»): ESP, авто-фарм, телепорты, движение, покупки, ивенты — всё в одном меню.

Текущая версия: **v0.6**

---

## Быстрый старт

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Skeltx/Mine-a-Mountain-Script/main/Start.lua"))()
```

Эта строка сама скачивает и запускает последнюю версию скрипта. Альтернатива — вставить содержимое `MaM v0.6.lua` целиком в окно инжектора и выполнить.

**Требования**
- Инжектор с поддержкой `game:HttpGet` / `loadstring` (проверено: Xeno).
- Полностью прогруженная игра (карта должна успеть стримиться).

## Возможности

### 💠 Вкладка Crystals
| Функция | Описание |
|---|---|
| **Crystal ESP** | Показывает кристаллы через стены: название, ценность, редкость, удача. Слежение за новыми кристаллами в реальном времени. |
| **Esp Size** | Размер текста ESP. |
| **Min Value** | Фильтр по минимальной ценности: кристаллы дешевле порога не отображаются и не подбираются автоматикой. Примеры формата: `500k`, `2m`, `1.5b`. Пустое поле — показывать всё. |
| Счётчик | Показывает, сколько кристаллов отслеживается и сколько отображается. |

### 👥 Вкладка Players
| Функция | Описание |
|---|---|
| **Player ESP** | Показывает игроков через стены (ник, дистанция). |
| **Esp Size** | Размер текста ESP. |

### 🏔 Вкладка Boulders
| Функция | Описание |
|---|---|
| **Boulder ESP** | Подсветка валунов на горе. |
| **Esp Size** | Размер текста ESP. |

**Boulder Farm** (правый блок) — специализируется на добыче рун:
| Функция | Описание |
|---|---|
| **Targets** | Выбор типов валунов (Mossite, Voltite, Gildrite, Rimeveil, Nocturnite) — фармит только отмеченные. |
| **Auto Farm** | Автоматически находит и разрушает выбранные валуны. |
| **Auto Rejoin On Finish** | Когда валуны на сервере кончились — перезаходится на новый сервер и продолжает. |

### 🎯 Вкладка Teleports
| Функция | Описание |
|---|---|
| **Top Crystals** | Кнопки «Top 1..5 Value / Luck / Weight» — мгновенный телепорт к самому дорогому / удачливому / тяжёлому кристаллу на сервере. |
| **Aim Teleport** | Телепорт к цели под прицелом. В бинде клавиша (задаётся рядом), активируется тумблером. |
| **TP Home** | Возврат на спавн. |
| **Sell All** | Мгновенная продажа всего содержимого рюкзака. |

### ⛏ Вкладка Farming
**Pickup** (левый блок):
| Функция | Описание |
|---|---|
| **Auto Pickup** | Автоподбор кристаллов вокруг персонажа с учётом фильтра ценности и свободного места в рюкзаке. |
| **Instant Prompt** | Мгновенное взаимодействие с кристаллами поблизости (без анимации удержания). |
| **Auto Rune Pickup** | Автоподбор рун. |
| Метка рюкзака | Показывает занятость рюкзака (текущий вес / вместимость / свободно). |

**Bomb Auto Buy** (левый блок, ниже):
| Функция | Описание |
|---|---|
| **Auto Buy Bombs** | Покупает все бомбы из шопа, как только появляется сток. |
| **Buy All Stock Now** | Разовая закупка всего доступного стока прямо сейчас. |

**Auto Farm Crystal** (правый блок) — майнит гору по стратегии:
| Функция | Описание |
|---|---|
| **Auto Farm** | Полный цикл: загрузка горы по контрольным точкам → поиск самой выгодной цели → добыча с автоприцелом → сбор лута. Статус всегда виден на метке. |
| **Focus Luck Crystals** | Режим «в первую очередь кристаллы с удачей». |
| **Min Luck Points** | Порог удачливости кристалла (1–1000) для режима Focus Luck. |
| **Auto Plant Luck Crystals** | Автоматически сажает кристаллы с удачей на свою грядку (plot) для бонусной удачи. |
| **Auto Sell At 50%** | При заполнении рюкзака наполовину сам идёт к точке продажи, продаёт всё и возвращается к майнингу. |

### ⚡ Вкладка Movement
| Функция | Описание |
|---|---|
| **Speed Boost** | Увеличенная скорость передвижения. |
| **Noclip** | Проход сквозь стены. |
| **Inf Jump** | Бесконечные прыжки. |
| **Fly** | Полёт (управление стандартными клавишами WASD + Space/Ctrl). |

### 📅 Вкладка Events (Halloween 2026)
| Функция | Описание |
|---|---|
| **Auto Candy** | Автоматический сбор конфет ивента. |
| **Auto Farm Ghost** | Авто-фарм призраков ивента. |
| **Auto Farm Pumpkin** | Авто-фарм тыкв ивента. |

### 📦 Вкладка Other
| Функция | Описание |
|---|---|
| **Collect Rune** | Автоматический сбор рун. |
| **Boulders ESP (Other)** | ESP валунов с фильтром по конкретным типам: выбираешь в списке — видишь только их. **Select All** включает все типы, присутствующие на сервере; **Clear Filter** сбрасывает выбор. При включении ESP валуются сразу все валуны сервера. |
| **Auto Farm (Other)** | Фармит только те валуны, что отмечены в Boulder ESP (Other). |
| **FPS Boost** | Отключает тени, туман и частицы — заметный прирост FPS. Ползунок **FPS Cap** (60–360) задаёт лимит кадров. |

(вкладка периодически пополняется новыми функциями)

### ⚙️ Вкладка Settings
| Функция | Описание |
|---|---|
| **Configs** | Полноценный менеджер конфигов: создать / загрузить / перезаписать / удалить / обновить список. Можно назначить конфиг автозагрузки при старте скрипта. Все настройки сохраняются. |
| **Themes** | Смена темы интерфейса (ThemeManager). |
| **Menu Bind** | Клавиша открытия/закрытия меню. |
| **Unload** | Полная выгрузка скрипта: восстанавливает свет/эффекты, отключает все подписи и циклы. |

## Прочее

- **Перезаход при падении сервера**: скрипт сам возвращается в игру (warm-пул серверов, авто-rejoin при критичных ошибках сети).
- **Статусные уведомления**: все действия фарм-движков отражаются в статус-метках и нотификациях; ошибки видны в консоли (F9).
- **Защита фильтров**: ESP и авто-фарм уважают фильтр Min Value — кристаллы ниже порога игнорируются.
- Модульная структура лежит в `Test/` (эксперименты), стабильная версия — `MaM v0.6.lua`.

## Важно
Скрипт написан в развлекательных целях. Использование может нарушать правила игры — используйте на свой риск.
